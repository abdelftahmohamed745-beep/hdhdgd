Nimbus Engine Android packaging — current delivery state

IMPLEMENTED IN SOURCE
- Android Gradle application module (arm64-v8a, API 24+, compile/target SDK 35).
- Native Java Activity + SurfaceView lifecycle integration.
- JNI bridge that owns an ANativeWindow reference and runs Nimbus Engine on a
  dedicated render thread.
- OpenGL ES 3 EGL surface/context initialization through the existing RHI.
- A small indexed demo mesh rendered through Nimbus Renderer.
- Lua is optional; native gameplay can initialize and run with scripting disabled.
- Android GitHub Actions workflow builds/validates the APK and uploads it as an
  Actions artifact.
- Optional Vercel deployment of the APK plus website when VERCEL_TOKEN is set.
